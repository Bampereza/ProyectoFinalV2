DIRECTORIO DE CONTACTOS BA

Proyecto desarrollado utilizando PHP, MySQL, Bootstrap y JavaScript.

REQUISITOS

* XAMPP
* Apache
* MySQL
* phpMyAdmin
* PHP

COMO VISUALIZAR EL PROYECTO

Se descarga la carpeta del proyecto y se mete a htdocs en xammp

luego se coloca este link para poder ver el proyecto desde xammp

http://localhost/Proyecto%201/

http://localhost/phpmyadmin/


CREAR BASE DE DATOS

Nombre de la base de datos:

directorio_contactos

Para utilizar la base de datos:

1. Abrir XAMPP.
2. Iniciar Apache y MySQL.
3. Entrar a phpMyAdmin.
4. Crear la base de datos `directorio_contactos`O Importar el archivo `directorio_contactos.sql`.
